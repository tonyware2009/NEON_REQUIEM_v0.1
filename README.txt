NEON REQUIEM v0.1

HOW TO RUN
1. Keep index.html, style.css, and game.js in the same folder.
2. Double-click index.html.
3. Play in a modern desktop browser.

CONTROLS
A / D or Left / Right: Move
W / Space / Up: Jump
Mouse: Aim
Left Mouse Button: Fire
R: Reload
Esc: Pause

Version 0.1 features:
- Side-scrolling cyberpunk arena
- Mouse aiming and rifle fire
- Ground troopers and flying drones
- Enemy projectiles
- Health and armor
- Ammo/reload system
- Ammo/armor pickups
- Score and kill counter
- Particle impacts, neon HUD, screen shake
- Start, pause, death and restart screens
